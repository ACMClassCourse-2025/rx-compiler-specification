# Lexical structure

The lexical chapters define [source input](input-format.md),
[keywords](keywords.md), [identifiers](identifiers.md), [comments](comments.md),
[whitespace](whitespace.md), and [tokens](tokens.md). Each chapter contains its
Lexer productions and linked syntax diagrams; [Notation](notation.md) explains
the grammar notation.

[Literal expressions](expressions/literal-expr.md) defines the values and range
rules of integer and boolean literals. [Parser conventions](grammar.md#contextual-punctuation)
specifies how combined punctuation is consumed in reference and generic contexts.
